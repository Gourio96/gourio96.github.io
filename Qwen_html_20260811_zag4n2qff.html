Guía de publicación paso a paso

Colgar la web en perfumesarabesoasistenerife.is-not-a.dev

Tu captura muestra un CNAME ya activo hacia gourio96.github.io. Eso significa que el dominio funcionará en cuanto la web exista en ese GitHub Pages. Sigue estos pasos exactos.

1Crear el repositorio correcto en GitHub

  1. Entra en github.com con la cuenta gourio96 (la misma del CNAME).
  2. Pulsa + (arriba derecha) → New repository.
  3. En “Repository name” escribe exactamente: gourio96.github.io (si ya existe, sáltate este paso).
  4. Márcalo Public y pulsa Create repository.
¿Por qué ese nombre? Porque tu CNAME apunta a gourio96.github.io (raíz). Solo el repositorio de usuario sirve la raíz; un repo de proyecto quedaría en gourio96.github.io/nombre-repo y el dominio no lo mostraría.

2Subir los archivos de la web

  1. Dentro del repositorio, pulsa Add file → Upload files.
  2. Arrastra estos 5 archivos de este paquete: index.html (tu web v5), estilos.css, colecciones.html, catalogo.html, ritual.html.
  3. Pulsa Commit changes.
  4. Ahora Add file → Create new file, escribe como nombre CNAME (sin extensión) y como contenido exactamente:
    perfumesarabesoasistenerife.is-not-a.dev
  5. Pulsa Commit changes.

3Activar GitHub Pages

  1. En el repositorio: Settings → Pages.
  2. En “Source” elige Deploy from a branch.
  3. En “Branch” selecciona main y carpeta / (root) → Save.
  4. Espera 1–3 minutos y abre: https://perfumesarabesoasistenerife.is-not-a.dev
🔒 SSL: GitHub Pages emite gratis el certificado Let’s Encrypt del dominio personalizado. En Settings → Pages verás “Enforce HTTPS” activarse solo (puede tardar hasta 10–15 min la primera vez). No toques nada más en Open Domains: tu CNAME ya está “Active”.

4Convertir el menú en páginas reales (multi-página)

Sí, puedo crearlas y ya están en este paquete. Para que el menú de index.html las abra, edita en GitHub el bloque <div class="nav-links"> de index.html (icono ✏️ del archivo → editar) y sustitúyelo por:

<div class="nav-links" id="navLinks">
  <a href="index.html">Inicio</a>
  <a href="colecciones.html">Colecciones</a>
  <a href="catalogo.html">Catálogo</a>
  <a href="ritual.html">El Ritual</a>
  <a href="index.html#blog">Blog</a>
  <a href="index.html#visita">Visítanos</a>
</div>

Y, si quieres que los dos paneles grandes “Ella / Él” del inicio también lleven a la página de colecciones, cambia en cada <article class="panel …"> el atributo data-ir="mujer" por onclick="location.href='colecciones.html'" (o déjalo como está: filtra el catálogo del inicio, que también es correcto).
